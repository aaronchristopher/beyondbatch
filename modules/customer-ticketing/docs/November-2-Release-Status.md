# November 2 development status

Customer ticketing belongs to the BeyondBatch repository under `modules/customer-ticketing/`. See `Implementation-Status.md` for the current tested behavior and incomplete production integrations, and the repository ADR 0008 for module ownership.

The existing private sample review is an interface demonstration. Its build source is included in this module; its account-specific hosting configuration and deployment history are not part of the public source. Importing code does not redeploy it or change its audience.

The planned November 6 live pilot remains conditional on an approved first mailbox, customer/PM mapping, verified identity and storage, approved Microsoft reads, a complete live processing path and the readiness gates. Classic Outlook desktop opening requires its own installed and tested integration. No automated sending is included.
